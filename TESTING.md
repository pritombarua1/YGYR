# Pre-event test checklist

Do this once on the real Wi-Fi (or hotspot), with the projector and 3 phones: one control phone and two players.

## Setup
- [ ] Run start.bat, choose a password. On the big screen: password, pick **5 winners**, tick **Longest throw** and **Bin throw**, **Who can enter: Both**, **Create game**. Write down the PIN.
- [ ] The big screen says **Connect your control phone now**. Scan it, enter the password: the big screen moves to the lobby by itself.
- [ ] Press **F**: full screen. Click once: "Click anywhere to turn sound on" disappears.
- [ ] Close the control page: the big screen says **Control phone offline**. Open it again: the warning goes.

## Joining
- [ ] Two phones join. Tags pop onto the wall with a sound; IDs are **Pilot-01**, **Pilot-02**. Each phone shows the **Screenshot this** code card once.
- [ ] A third tab tries the same name: it asks for the rejoin code. The right code gets them back as the same pilot.
- [ ] Phone A: **Start a team**. Phone B: **Ask to join** it. Phone A buzzes and shows the request: **Accept**. Both passes show the team; the big screen tags show the team name.
- [ ] Phone C asks too, phone A **Declines**: C is back to the team list.

## Rules (from the control phone)
- [ ] Next steps through the rules (page turn + tear sound on the big screen), including **Fly solo or as a team**. Tap a rule to jump. Phones show the same rule.

## Round 1
- [ ] Pilot-01's phone: "You're up!" (sound + buzz). Pilot-02's: "You're next".
- [ ] When a team comes up, its members are called one after another; the big screen shows the team formation.
- [ ] Type metres → **Save**: landing on the big screen, next pilot called. Top 5 is sorted.
- [ ] **Undo**: the distance clears and Pilot-01 is called again.
- [ ] **Skip for now** and **Not here** behave; **Back** brings them in again.
- [ ] Last throw: the control phone asks **Start Round 2?**

## Round 2
- [ ] Quick **+** taps all count; **Done** calls the next pilot. Round end asks **On to the winners?**

## Winners
- [ ] **Reveal 5th place**: drumroll, "And in 5th place…", card with spotlight and seal.
- [ ] **Reveal all the rest**: 4th, 3rd, 2nd, 1st one by one; 1st gets the fanfare and big confetti. Winners' phones celebrate at the same moment.
- [ ] The results QR appears; `/results` shows everyone, search works, your own row is highlighted.
- [ ] Refresh the big screen: it comes straight back to the revealed podium (no replay).

## Restart drill (worth doing once)
- [ ] Close start.bat, run it again. Big screen: **Resume a game** with the PIN. A player rejoins with name + code and still has their points.

## Other challenge settings (quick)
- [ ] New game with **Longest throw** only: steps are Lobby, Rules, Distance, Winners. Podium shows metres.
- [ ] New game with **Bin throw** only: 5 throws per entry, podium shows "4/5 in".
- [ ] Control **Menu → Challenges and teams** is greyed out once the first round has started.

## Control phones and prizes
- [ ] Control **Menu → Control phones → Add a control phone**: a second phone scans the QR, types a name, and is in without the password. It shows as "helper".
- [ ] **Remove** it: that phone goes back to the login screen straight away and its old QR doesn't work.
- [ ] Winners list on the control phone: one person per place, with their team name, and "Prizes to hand out: 3".

## Updates
- [ ] Laptop corner **Menu → Check for updates** says "Up to date" (or lists new updates).

## Before the real thing
- [ ] Create a new game with today's settings: **Longest throw** only, **3 winners**, **Who can enter: Both** (the defaults).
